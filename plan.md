# Implementation Plan: Migrate to uv Dependency Management

## Goal
Migrate the `ai-photo-editor` project from `setup.py` and `requirements.txt` to a modern `uv`-based configuration using `pyproject.toml`.

## Tasks
1. **Initialize uv Project**:
   - Run `uv init` to initialize the project structure.
   - Configure `pyproject.toml` with metadata extracted from `setup.py`:
     - Name: `ai-photo-editor`
     - Version: `0.1.0`
     - Description: `AI-powered RAW photo editor using Ollama`
     - Python requirement: `>=3.7`
   - File: `pyproject.toml`

2. **Migrate Dependencies**:
   - Add the following dependencies to `pyproject.toml` using `uv add`:
     - `requests>=2.28.0`
     - `Pillow>=9.0.0`
     - `rawpy>=0.15.0`
     - `numpy>=1.21.0`
     - `imageio>=2.25.0`
   - File: `pyproject.toml`

3. **Configure CLI Entry Point**:
   - Define the console script in `pyproject.toml` under `[project.scripts]`:
     - `ai-photo-editor = "ai_photo_editor:main"`
   - File: `pyproject.toml`

4. **Update Documentation**:
   - Update `README.md` to replace `pip install -r requirements.txt` with `uv sync` or `uv run`.
   - Update usage instructions to mention `uv run ai-photo-editor`.
   - File: `README.md`

5. **Cleanup Legacy Files**:
   - Delete `requirements.txt`.
   - Delete `setup.py`.

6. **Verification**:
   - Run `uv sync` to ensure the environment is created and `uv.lock` is generated.
   - Run existing tests: `uv run pytest tests/test_unit.py`.
   - Verify the CLI command works: `uv run ai-photo-editor --help` (or similar check).

## Files to Modify
- `README.md` - Update installation and usage instructions.
- `pyproject.toml` - New file created via `uv init` and modified to include dependencies and scripts.

## New Files
- `pyproject.toml` - The new source of truth for project configuration and dependencies.
- `uv.lock` - Generated by `uv` for deterministic builds.

## Dependencies
- Task 2 and 3 depend on Task 1.
- Task 4 and 5 should be done after Task 1, 2, and 3 are verified.
- Task 6 is the final validation step.

## Risks
- **Python Version**: `setup.py` specifies `>=3.7`, but some `uv` defaults or modern dependencies might require higher (e.g., 3.8+). This should be verified during `uv sync`.
- **Dependency Conflicts**: Moving to `uv` might reveal version conflicts that were previously ignored by `pip` if `uv`'s resolver is stricter.
- **Test Execution**: Need to ensure `pytest` is available as a dev dependency via `uv add --dev pytest`.
